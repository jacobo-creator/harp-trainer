How the technique hint works

Pick your harmonica's key above. As you play, the app shows which hole and breath you're hitting — +4 = blow 4, -4 = draw 4, and apostrophes mark bends (-3' = ½-step bend, -3'' = whole-step). Watch the needle to train your bends to the right pitch.

Kalimba layout (21 keys)

The centre tine is the longest and lowest note (F). Numbers match your kalimba's stickers: 1–7 = C–B, a dot above = higher octave, a dot below = the bass notes.

Violin — first position

The tab shows the string and finger — e.g. A2 = A string, 2nd finger; D0 = open D. 0 = open string, then fingers 1 2 3 4 go up.

Standard first-position notes (with finger tapes). The staff shows if a note is sharp/flat (a “high” or “low” finger).

Lyre harp strings

Each string is one note, so the tab is just the note letter + octave — e.g. C4, G5. Sharps/flats aren't on the lyre, so the app suggests the nearest string (the blue tab marked *).
